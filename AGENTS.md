# Правила проекта

- Колясик отвечает за API, базу, безопасность и деплой; Аслан — за интерфейс; Кирилл — за спецификацию, контент и отчёт.
- Использовать только вымышленные персональные данные.
- Секреты хранить в окружении; не включать их в код, ответы API, логи и коммиты.
- Определять текущего студента по серверной сессии. Проверять доступ к объекту при каждом чтении и изменении.
- Изменения контракта отражать в docs/api.md. Несогласованные продуктовые решения отмечать как черновик.
- Проверять типы и сборку после изменений сервера. Для авторизации добавить интеграционные проверки разделения данных двух студентов.
- Не заявлять реализацию или проверку функций, которые ещё не готовы.
