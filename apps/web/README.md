# Интерфейс — МУКПиД · Онлайн деканат

Приложение Аслана. Контракт API: [../../docs/api.md](../../docs/api.md).

> **Статус:** интерфейс работает на демо-данных (`src/data/mock.ts`) и `localStorage`.
> К API (`apps/api`) пока не подключён — это следующий шаг.


Фронтенд по макетам «Графитово-синий» и «Туман» (светлая и тёмная тема, 12 экранов).
Концепт для конкурса «Вайб-кодинг». Не официальный сервис вуза, все данные вымышлены.

**Стек:** React 19 + TypeScript (strict) + Vite + React Router. Без UI-библиотек: свои компоненты и CSS-переменные.

## Запуск

```bash
cd apps/web
npm install
npm run dev            # http://localhost:5173
npm run build          # обычная сборка в dist/
npm run build:single   # весь сайт одним файлом: dist-single/index.html
```

Тестовые аккаунты: `student@edu.mukpid.ru` / `teacher@mukpid.ru`; пароли задаются через переменные окружения при заполнении базы.

## Оформление

- Три цветовых варианта: **«Туман»** (основной, по умолчанию), **«Графитово-синий»** и **«Новогодняя»**.
- «Новогодняя»: падающий снег (canvas), гирлянды и ёлки с поочерёдно вспыхивающими огоньками, отсчёт до Нового года. Декор — в `src/components/newyear/`.
- Две темы: светлая и тёмная (по умолчанию — как в системе).
- Переключение: Профиль → «Оформление». Тему также меняет кнопка с луной/солнцем в шапке.
- Выбор сохраняется в `localStorage`.
- Все цвета — в `src/styles/tokens.css`. Вариант задаёт `data-variant`, тему — `data-theme` на `<html>`.

## Экраны

| Роль | Маршрут | Экран |
|---|---|---|
| — | `#/login` | Вход (роль студент/преподаватель) |
| Студент | `#/student` | Главная: следующая пара, баллы, дедлайны, заявки, объявления |
| | `#/student/schedule` | Расписание: неделя/день, переносы и отмены, листание недель |
| | `#/student/grades` | Успеваемость: осень/весна, средний балл, допуск |
| | `#/student/requests` | Заявки и справки: создание, фильтр, статусы, отмена |
| | `#/student/notifications` | Уведомления: прочитать, настройки рассылки |
| | `#/student/profile` | Профиль + оформление + выход |
| Преподаватель | `#/teacher` | Главная: следующее занятие, обращения, ведомости |
| | `#/teacher/schedule` | Расписание |
| | `#/teacher/gradebook` | Ведомость: ввод баллов 0–100, авто-оценка, сохранение |

| | `#/teacher/profile` | Профиль |

На экранах уже 860px сайдбар превращается в верхнюю панель и нижнюю навигацию, как в макете «Главная на телефоне».
Вёрстка проверена от 360px — без горизонтальной прокрутки.

## Структура

```
src/
  styles/tokens.css     — палитры 2 варианта × 2 темы
  styles/global.css     — вся вёрстка и адаптив
  context/              — настройки (тема/вариант), авторизация, данные, тосты
  data/mock.ts          — демо-данные (расписание, баллы, заявки, обращения…)
  lib/                  — форматирование дат, шкала оценок, localStorage
  components/           — Layout (сайдбар, мобильная навигация), ui, расписание, поиск, иконки
  pages/                — Login, Profile, student/*, teacher/*
```

## Что важно знать

- **Бэкенда нет.** Вход, заявки, ведомости и обращения работают на клиенте и хранятся в `localStorage`.
  Подключать API нужно в `src/context/auth.tsx` и `src/context/data.tsx` — интерфейсы контекстов можно не менять.
  Кнопка «Сбросить демо-данные» в профиле возвращает исходное состояние.
- **Демо-время:** «сейчас» зафиксировано на среду, 11 ноября 2026, 10:20 (`DEMO_NOW` в `data/mock.ts`) — как на макетах.
  Для реальной работы замените на `new Date()`.
- **HashRouter** (`#/student/...`) — сайт работает на любом статическом хостинге без настройки сервера.
- Шрифты: Manrope (текст) и Unbounded (заголовки) подключены локально через `@fontsource`. В макете
  заголовки набраны широким гротеском; Unbounded — ближайший свободный аналог с кириллицей.
- Герб вырезан из макета (`src/assets`). Если есть исходник в векторе, лучше заменить.
